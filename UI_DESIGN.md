# UI Design

## Design Direction

Neuronix uses a modern, Apple-inspired, premium healthcare UI with:

- glassmorphism surfaces
- blue and white palettes
- calm medical aesthetics
- responsive layouts for mobile and desktop
- professional and accessible interactions

## Key Screens

- Onboarding
- Patient login/register
- Doctor login/dashboard
- Symptom intake
- Report upload
- AI analysis results
- Appointment management
- Prescription review
- Admin analytics
